# 50 States Study

Practice naming all 50 U.S. states, numbered to match the class worksheet.

- **Drag & Drop** – drag names from the word bank onto the numbered boxes or right onto the map (or tap a name, then tap a box).
- **Fill In** – type each name; the word bank crosses names off as you go, and "Check answers" flags spelling slips.
- **Print** – a one-page blank worksheet (map, 50 lines, 3 questions, word bank) or an answer key.

Progress is saved in the browser.
