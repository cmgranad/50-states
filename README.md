# 50 States Study

Practice naming all 50 U.S. states, numbered to match the class worksheet.

- **Practice** – instant, gentle feedback: right answers lock in green on the map, wrong ones say "try again." Hints anytime.
- **Test** – like the real quiz: answers are checked only when you tap "I'm finished," then you get a friendly results card and can practice just the ones you missed.
- Both work as **Drag & Drop** or **Fill In**, always with the word bank.
- **Print** – a one-page blank worksheet (map, 50 lines, 3 questions, word bank) or an answer key.

Progress is saved in the browser.
